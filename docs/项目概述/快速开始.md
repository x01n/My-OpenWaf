## 简介
本指南面向首次接触 My-OpenWaf 的用户，帮助你在最短时间内完成安装、构建与运行，并通过 Docker 实现一键部署。文档覆盖：环境前置、本地与脚本构建、源码手动构建、Docker 镜像构建与容器运行、基本配置项、首次启动到可登录的完整流程，以及常见排障建议。

所有命令均逐条对应仓库内的脚本或配置来源，不凭经验补全。密钥、令牌与口令一律以 `{占位}` 表达。

## 项目结构
My-OpenWaf 是前后端合一的单二进制程序：后端由 Go 编写，`internal/app.Run` 串联控制面与数据面；前端基于 Next.js 以静态导出（`output: "export"`，产物目录 `out`）构建后复制到 `internal/core/adminweb/dist`，编译期嵌入后端。

## 核心组件
- 应用入口与启动：`main()` 先识别子命令（`reset-admin-password` / `help`），可选拉起 pprof，随后调用 `app.Run()`。参考 [cmd/main.go:13-50](file://cmd/main.go#L13-L50)。
- 运行时与配置：`NewRuntime` 调用 `LoadConfigFromEnv` 读取环境变量，校验引导配置后打开主库与日志库，可选建立 Redis，并初始化缓存与快照持有者。参考 [internal/core/runtime.go:23-60](file://internal/core/runtime.go#L23-L60)。

- 默认数据与凭据：`SeedDefaults` **仅** 在首次运行且无 `admin` 账号时创建管理员并返回随机口令；**不预置任何 API 令牌**（令牌须由已登录管理员主动创建）。参考 [internal/store/auth/seed.go:14-56](file://internal/store/auth/seed.go#L14-L56)。
- 前端构建与嵌入：`bun run build` 在 `next build` 后将 `out` 复制入 `internal/core/adminweb/dist`。参考 [frontend/package.json:8](file://frontend/package.json#L8)、[scripts/build.sh:4-8](file://scripts/build.sh#L4-L8)。

cd .. && CGO_ENABLED=1 go build -tags=quickjs -ldflags="-s -w" -o bin/my-openwaf ./cmd/...

### 部署方式

#### 本地运行
直接运行构建产物即可；应用会自动迁移数据库并在首次运行生成管理员口令。环境变量可覆盖驱动、DSN、数据目录与管理端口（见下节配置项表）。

```bash
# 覆盖默认配置后启动（密钥/口令一律 {占位}）
MY_OPENWAF_DB_DRIVER=sqlite \
MY_OPENWAF_DATA=./data \
MY_OPENWAF_ADMIN_BIND=:9443 \
MY_OPENWAF_JWT_SECRET={占位} \
./bin/my-openwaf
```

## 性能考虑
- 默认 SQLite 适合小规模与本地验证；生产可切换 MySQL/PostgreSQL 并配置连接池与索引。
- 启用 Redis 可在多节点场景下共享限流窗口与配置同步。
- 按站点动态启停监听器，减少空闲资源占用；TLS/SNI 配置变更会触发受影响监听器热重启。
- 前端为静态导出并内嵌二进制，省去独立静态服务的访问开销。

## 故障排查指南
- 前端构建失败：确认 Bun 版本满足要求且存在 `frontend/bun.lock`，用 `bun install --frozen-lockfile`。参考 [frontend/package.json:6-8](file://frontend/package.json#L6-L8)。
- Go 构建失败：Go 需 1.27.1+，并确保已安装 GCC（QuickJS CGO）；用 `CGO_ENABLED=1` 编译。参考 [README.md:295](file://README.md#L295)。
- 首启未见凭据：非首次运行时 `admin` 账号已存在，`SeedDefaults` 不再返回口令；如需重置用子命令。参考 [internal/store/auth/seed.go:14-56](file://internal/store/auth/seed.go#L14-L56)。
- 端口占用 / 容器无法访问：确认 `-p 9443:9443` 与 `MY_OPENWAF_ADMIN_BIND`。参考 [Dockerfile:25-26](file://Dockerfile#L25-L26)。

```bash
# 忘记管理员口令时重置（对应 cmd/main.go:16-25）
bin/my-openwaf reset-admin-password admin {新口令}
```

## 结论
基于 Go 与 Bun 环境，可用 `scripts/build.sh` / `scripts/build.ps1` 一键完成前端、WASM 与后端构建，或直接以 Docker 部署。首次运行仅自动生成管理员口令（不含 API Token），妥善保存后用 `https://localhost:9443` 登录后台。后续可按需切换数据库与启用 Redis 以满足更高可用与性能要求。
